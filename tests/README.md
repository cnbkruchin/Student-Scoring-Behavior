# ชุดทดสอบตรรกะฝั่งเซิร์ฟเวอร์

ทดสอบโค้ด `.gs` ทั้งหมดได้บนเครื่องโดยไม่ต้องเปิด Google Apps Script
โดยจำลองบริการของ Google (SpreadsheetApp, PropertiesService, LockService, Utilities) ขึ้นมาใน Node.js

```bash
cd tests
node run.js              # ทดสอบไฟล์ต้นฉบับใน apps-script/
node run.js --bundle     # ทดสอบไฟล์รวมใน dist/ ที่จะเอาไปติดตั้งจริง
```

ผลลัพธ์ที่คาดหวัง: **ผ่าน 117 รายการ · ไม่ผ่าน 0 รายการ** ทั้งสองแบบ

`--bundle` ใช้ยืนยันว่าไฟล์ที่รวมแล้วด้วย `node build/bundle.js` ทำงานเหมือนต้นฉบับทุกประการ
ควรรันก่อนนำไฟล์ใน `dist/` ไปวางใน Apps Script ทุกครั้ง

## สิ่งที่ทดสอบ

|-------|----------------|
| ติดตั้งระบบ | สร้างชีตครบ ใส่หลักเกณฑ์จริงของโรงเรียน 87 ข้อ · รหัสเกณฑ์ไม่ซ้ำ · รหัสเดิมที่ซ้ำกันยังอยู่ครบ |
| เข้าสู่ระบบ | รหัสผ่านไม่ถูกเก็บเป็นข้อความธรรมดา · ข้อความ error เหมือนกันทั้งกรณีไม่มีผู้ใช้และรหัสผิด · token ปลอมถูกปฏิเสธ |
| สิทธิ์ตามบทบาท | ครูผู้สอนอนุมัติไม่ได้ · ครูที่ปรึกษาเห็นเฉพาะห้องตน · ความผิดร้ายแรงต้องให้ฝ่ายกิจการนักเรียนพิจารณา |
| กลไกคะแนน | คะแนนไม่เปลี่ยนก่อนอนุมัติ · เพดาน 100 ทำงาน · ความดีสะสมไม่ถูกลบเมื่อทำผิด · ยอดในบัญชีเดินตรงกับยอดคงเหลือ |
| ป้องกันคะแนนเฟ้อ | เกินเพดานครั้งต่อภาคเรียนถูกปฏิเสธ |
| กระดานเกียรติยศ | คนที่เคยทำผิดถูกตัดออกแม้คะแนนสูงสุด · การเรียงเมื่อคะแนนเท่ากัน · หน้าสาธารณะไม่มีข้อมูลด้านลบหลุดออก |
| PDPA | ปกปิดนามสกุลเมื่อผู้ปกครองไม่ยินยอม |
| เพิกถอน/อุทธรณ์ | คืนคะแนนถูกต้อง · กลับขึ้นกระดานได้ · ความดีสะสมไม่ถูกแตะต้อง |
| ความถูกต้องของยอด | คำนวณใหม่จากบันทึกทั้งหมดได้ผลตรงกับยอดที่เดินมา |
| รายงาน | รายงานทั้ง 9 ประเภทสร้างได้ · R01 แสดงความดีก่อนความผิด |
| นำเข้าข้อมูล | ตรวจสอบแล้วยังไม่เขียนลงชีต · นำเข้าซ้ำเป็นการอัปเดตไม่สร้างซ้ำ · จับแถวที่ผิดพร้อมบอกสาเหตุ · อ่านวันที่ พ.ศ. ได้ · ปฏิเสธรหัสเดิมที่ซ้ำกันพร้อมบอกวิธีแก้ · แบบฟอร์มที่ดาวน์โหลดนำกลับเข้าระบบได้ทันที |

| จัดการหลักเกณฑ์ | เพิ่ม/แก้ไข/ลบได้ · เกณฑ์ที่ถูกใช้แล้วจะปิดการใช้งานแทนการลบ · ครูผู้สอนแก้ไม่ได้ |

## เมื่อแก้โค้ดแล้วควรรันซ้ำ

ทุกครั้งที่แก้ไฟล์ `.gs` ให้รัน `node run.js` ก่อนนำขึ้นระบบจริง
ถ้ามีรายการไหนไม่ผ่าน แปลว่าพฤติกรรมของระบบเปลี่ยนไปจากที่ออกแบบไว้
