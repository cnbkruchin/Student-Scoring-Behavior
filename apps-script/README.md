# เว็บแอประบบคะแนนความประพฤติ (Google Apps Script + Google Sheets)

ระบบพร้อมใช้งานจริงที่ใช้ **Google Sheets เป็นฐานข้อมูล** และ **Google Apps Script เป็นเว็บแอป**

| ข้อดี | รายละเอียด |
|-------|-----------|
| ไม่มีค่าใช้จ่าย | ใช้บัญชี Google ของโรงเรียนที่มีอยู่แล้ว ไม่ต้องเช่าโฮสต์หรือโดเมน |
| ข้อมูลเป็นของโรงเรียน | ทุกอย่างอยู่ใน Google Drive ของโรงเรียน ไม่ผ่านบุคคลที่สาม |
| ใช้ได้ทุกอุปกรณ์ | คอมพิวเตอร์ แท็บเล็ต และมือถือ ผ่านเบราว์เซอร์ ไม่ต้องติดตั้งแอป |
| ครูไม่ต้องมีบัญชี Google | ระบบมีหน้าเข้าสู่ระบบของตัวเอง ใช้ชื่อผู้ใช้และรหัสผ่านที่โรงเรียนกำหนด |
| ดูแลต่อได้ | ถ้าผู้พัฒนาไม่อยู่ ครูคอมพิวเตอร์เปิดชีตดูข้อมูลดิบได้ทันที ไม่มีข้อมูลติดล็อก |

---

## สิ่งที่ระบบทำได้

**ระบบหลังบ้าน (ต้องเข้าสู่ระบบ)**

- **แดชบอร์ด** — ตัวเลขสรุป กราฟแนวโน้ม 6 เดือน การกระจายตามระดับความเสี่ยง
  คะแนนเฉลี่ยรายระดับชั้น พฤติกรรมที่พบบ่อย และกระดานเกียรติยศ
- **บันทึกพฤติกรรม** — เลือกความดี/ความผิด ค้นหานักเรียน เลือกเกณฑ์ (คะแนนเติมอัตโนมัติ)
  ออกแบบให้ใช้บนมือถือได้ในไม่กี่วินาที
- **รออนุมัติ** — ผู้มีอำนาจพิจารณาอนุมัติหรือไม่อนุมัติ คะแนนเดินเมื่ออนุมัติแล้วเท่านั้น
- **นักเรียน** — ค้นหา ดูประวัติรายบุคคลพร้อมกราฟคะแนน เพิ่ม/แก้ไขข้อมูล เพิกถอนบันทึก
- **กระดานเกียรติยศ** — 10 อันดับต่อระดับชั้น พร้อมปุ่มประกาศขึ้นหน้าเว็บสาธารณะ
- **รายงาน 9 ประเภท** — ดูตัวอย่างบนหน้าจอ และดาวน์โหลดเป็น **Excel (.xlsx)** หรือ **PDF**
- **ตั้งค่าระบบ** — ค่าตั้งค่า ผู้ใช้งาน นำเข้ารายชื่อจาก CSV เครื่องมือซ่อมข้อมูล ร่องรอยการใช้งาน

**หน้าเว็บสาธารณะ (ไม่ต้องเข้าสู่ระบบ)**

กระดานเกียรติยศอย่างเดียว **ไม่มีข้อมูลด้านลบใด ๆ ออกจากระบบ** และปกปิดนามสกุลอัตโนมัติ
สำหรับนักเรียนที่ผู้ปกครองไม่ได้ให้ความยินยอมตาม PDPA

## ขั้นตอนติดตั้ง (ประมาณ 20 นาที)

### 1. สร้างไฟล์ Google Sheets

เข้า https://sheets.new **ด้วยบัญชี Google ของโรงเรียน** (ไม่ใช่บัญชีส่วนตัวของครูคนใดคนหนึ่ง
เพราะเมื่อครูย้ายโรงเรียน ข้อมูลจะติดไปด้วย) แล้วตั้งชื่อไฟล์ เช่น
`ฐานข้อมูลความประพฤตินักเรียน โรงเรียนจุนวิทยาคม`

### 2. เปิด Apps Script

เมนู **ส่วนขยาย (Extensions) → Apps Script**

### 3. เปิดให้แก้ไขไฟล์ตั้งค่า

ในหน้า Apps Script กด **⚙️ การตั้งค่าโครงการ (Project Settings)**
แล้วติ๊ก **แสดงไฟล์ manifest "appsscript.json" ในตัวแก้ไข**

### 4. คัดลอกไฟล์ทั้งหมด

สร้างไฟล์ตามรายการนี้ (กด **+** ข้างคำว่า "ไฟล์") แล้ววางเนื้อหาจากโฟลเดอร์ `apps-script/`

| ชื่อไฟล์ที่ต้องตั้งใน Apps Script | ชนิด | ไฟล์ต้นทาง |
|--------------------------------|------|-----------|
| `appsscript.json` | (มีอยู่แล้ว) | `appsscript.json` |
| `00_Config` | สคริปต์ | `00_Config.gs` |
| `01_Db` | สคริปต์ | `01_Db.gs` |
| `02_Auth` | สคริปต์ | `02_Auth.gs` |
| `03_Scoring` | สคริปต์ | `03_Scoring.gs` |
| `04_Api` | สคริปต์ | `04_Api.gs` |
| `05_Reports` | สคริปต์ | `05_Reports.gs` |
| `06_Setup` | สคริปต์ | `06_Setup.gs` |
| `07_WebApp` | สคริปต์ | `07_WebApp.gs` |
| `Index` | HTML | `Index.html` |
| `Style` | HTML | `Style.html` |
| `Script` | HTML | `Script.html` |
| `ScriptCharts` | HTML | `ScriptCharts.html` |
| `ScriptViews` | HTML | `ScriptViews.html` |

> ชื่อไฟล์ต้องตรงตามนี้ทุกตัวอักษร เพราะโค้ดอ้างอิงกันด้วยชื่อ
> (ไฟล์สคริปต์ไม่ต้องพิมพ์ `.gs` ระบบเติมให้เอง ส่วนไฟล์ HTML ไม่ต้องพิมพ์ `.html`)

**ทางลัดสำหรับผู้ที่ใช้ clasp เป็น**

```bash
npm install -g @google/clasp
clasp login
clasp clone <SCRIPT_ID>          # เอา SCRIPT_ID จากหน้าการตั้งค่าโครงการ
cp apps-script/* <โฟลเดอร์ที่ clone มา>/
clasp push
```

### 5. บันทึกและติดตั้งระบบ

1. กด **บันทึก (💾)** ในหน้า Apps Script
2. กลับไปที่ไฟล์ Google Sheets แล้ว **โหลดหน้าใหม่ (F5)**
3. จะมีเมนูใหม่ **⚙️ ระบบคะแนนความประพฤติ** โผล่ขึ้นมาบนแถบเมนู
4. เลือก **1. ติดตั้งระบบ** → กด **อนุญาต (Authorize)** ให้สิทธิ์ตามที่ระบบขอ
   - หน้าจอเตือน "Google ยังไม่ได้ตรวจสอบแอปนี้" ให้กด **ขั้นสูง (Advanced)**
     → **ไปที่ ... (ไม่ปลอดภัย)** ซึ่งปลอดภัยเพราะเป็นสคริปต์ที่เราวางเอง ไม่ใช่ของคนอื่น
5. รอสักครู่ ระบบจะสร้างชีต 11 แผ่นและใส่หลักเกณฑ์ตั้งต้น 45 ข้อให้
6. เลือก **2. สร้างบัญชีผู้ดูแลระบบ** แล้วกรอกชื่อผู้ใช้ ชื่อ-สกุล และรหัสผ่าน

### 6. เผยแพร่เว็บแอป

ในหน้า Apps Script กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้ใหม่ (New deployment)**

| ช่อง | ค่าที่ต้องเลือก |
|------|----------------|
| ประเภท | **เว็บแอป (Web app)** |
| คำอธิบาย | เช่น `เวอร์ชัน 1` |
| ดำเนินการในฐานะ (Execute as) | **ฉัน (Me)** — บัญชีโรงเรียนที่เป็นเจ้าของไฟล์ |
| ผู้ที่มีสิทธิ์เข้าถึง (Who has access) | **ทุกคน (Anyone)** |

> ที่ต้องตั้งเป็น "ทุกคน" เพราะระบบมี**หน้าเข้าสู่ระบบของตัวเอง**อยู่แล้ว
> ครูจึงไม่จำเป็นต้องมีบัญชี Google และไม่ต้องแชร์สิทธิ์แก้ไขไฟล์ Sheets ให้ใครเลย
> ผู้ที่ไม่มีชื่อผู้ใช้จะเห็นได้แค่หน้าเข้าสู่ระบบเท่านั้น

กด **ทำให้ใช้งานได้** แล้ว **คัดลอก URL ของเว็บแอป** เก็บไว้ — นั่นคือลิงก์ระบบของโรงเรียน

### 7. ทดลองใช้

เปิด URL ที่ได้ แล้วเข้าสู่ระบบด้วยบัญชีผู้ดูแลระบบที่สร้างไว้

อยากลองก่อนใส่ข้อมูลจริง? กลับไปที่ Sheets เลือกเมนู
**⚙️ ระบบคะแนนความประพฤติ → ใส่ข้อมูลตัวอย่างสำหรับทดลองใช้**
จะได้นักเรียนตัวอย่าง 12 คน และบัญชีทดลอง 4 บัญชี (รหัสผ่าน `demo1234` ทุกบัญชี)

> ⚠️ **ลบบัญชีทดลองและข้อมูลตัวอย่างทั้งหมดก่อนใช้งานจริง**

### 8. ตั้งให้ประกาศกระดานเกียรติยศอัตโนมัติ (ไม่บังคับ)

ในหน้า Apps Script กด **⏰ ทริกเกอร์ (Triggers) → เพิ่มทริกเกอร์**

| ช่อง | ค่า |
|------|-----|
| ฟังก์ชันที่จะเรียกใช้ | `publishLeaderboard_` |
| แหล่งที่มาของเหตุการณ์ | ตัวจับเวลา (Time-driven) |
| ประเภท | ตัวจับเวลารายวัน (Day timer) |
| ช่วงเวลา | 6.00 น. – 7.00 น. |

### 9. ลิงก์หน้าเว็บสาธารณะ

เอา URL ของเว็บแอปมาต่อท้ายด้วย `?page=board`

```
https://script.google.com/macros/s/XXXXXXXX/exec?page=board
```

นำลิงก์นี้ไปฝังในเว็บไซต์โรงเรียนหรือติด QR Code ไว้ที่บอร์ดประชาสัมพันธ์ได้เลย
(หาลิงก์นี้ได้จากในระบบที่ **ตั้งค่าระบบ → เครื่องมือ**)

| ค่า | ค่าเริ่มต้น | ควรพิจารณา |
|-----|------------|-----------|
| ปีการศึกษาปัจจุบัน | 2569 | เปลี่ยนทุกต้นปีการศึกษา |
| คะแนนตั้งต้น | 100 | ตามระเบียบโรงเรียน |

(แก้ในชีตได้โดยตรง หรือเพิ่มแถวใหม่ก็ได้ — ระบบอ่านตามหัวตาราง ไม่ใช่ตำแหน่งคอลัมน์)

## บทบาทและสิทธิ์

| บทบาท | บันทึก | อนุมัติ | เพิกถอน | ดูทั้งโรงเรียน | รายงาน | จัดการผู้ใช้ |
|--------|--------|---------|---------|---------------|--------|-------------|
| ผู้ดูแลระบบ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| ฝ่ายกิจการนักเรียน | ✅ | ✅ | ✅ | ✅ | ✅ | ❌ |
| ผู้บริหาร | ❌ | ❌ | ❌ | ✅ | ✅ | ❌ |
| หัวหน้าระดับชั้น | ✅ | ✅ | ❌ | เฉพาะระดับตน | ✅ | ❌ |
| ครูที่ปรึกษา | ✅ | ✅ (ยกเว้นความผิดร้ายแรง) | ❌ | เฉพาะห้องที่ปรึกษา | เฉพาะห้องตน | ❌ |
| ครูผู้สอน | ✅ | ❌ | ❌ | ค้นหาเพื่อบันทึกได้ | ❌ | ❌ |

**การกำหนดขอบเขต** (ช่อง "ขอบเขตความรับผิดชอบ" ตอนสร้างผู้ใช้)

- ครูที่ปรึกษา ใส่ห้องคั่นด้วยจุลภาค เช่น `1/1,1/2`
- หัวหน้าระดับชั้น ใส่ระดับชั้น เช่น `1,2,3`
- เว้นว่าง = เห็นทั้งโรงเรียน

**กติกาที่ระบบบังคับไว้เสมอ**

1. คะแนนเปลี่ยนเมื่อบันทึก**ได้รับอนุมัติ**แล้วเท่านั้น
2. **อนุมัติบันทึกของตัวเองไม่ได้** (ยกเว้นผู้ดูแลระบบและฝ่ายกิจการนักเรียน)
3. **ความผิดระดับร้ายแรง (ระดับ 3–4) ต้องให้ฝ่ายกิจการนักเรียนพิจารณา** ครูที่ปรึกษาอนุมัติไม่ได้
4. ทุกการกระทำถูกบันทึกใน `บันทึกการใช้งาน` ตรวจสอบย้อนหลังได้

## ข้อจำกัดที่ต้องรู้ก่อนตัดสินใจ

| เรื่อง | ข้อจำกัด | ทางแก้ |
|-------|---------|--------|
| ขนาดข้อมูล | Google Sheets ไหวถึงประมาณ **50,000 แถว** ต่อชีตโดยไม่ช้า | โรงเรียนขนาด 1,000 คน บันทึกปีละ ~10,000 รายการ ใช้ได้สบายหลายปี ถ้าเกินให้ย้ายข้อมูลปีเก่าไปไฟล์เก็บถาวรทุกสิ้นปี |
| ความเร็ว | Apps Script ช้ากว่าเว็บแอปทั่วไป แต่ละคำสั่งใช้เวลา 1–3 วินาที | ยอมรับได้สำหรับงานโรงเรียน ถ้าต้องการเร็วกว่านี้ต้องย้ายไปฐานข้อมูลจริงตาม `db/schema.sql` |
| โควตา | ส่งออกรายงานได้ประมาณ 20,000 ครั้งต่อวัน สคริปต์รันได้ครั้งละไม่เกิน 6 นาที | เพียงพออย่างมากสำหรับโรงเรียนเดียว |
| ผู้ใช้พร้อมกัน | ประมาณ 20–30 คนพร้อมกันยังลื่น | ช่วงหน้าเสาธงที่ครูบันทึกพร้อมกันเยอะอาจช้าลงเล็กน้อย |
| รหัสผ่าน | ใช้ SHA-256 วนซ้ำ 1,000 รอบ (Apps Script ไม่มี bcrypt ให้ใช้) | ปลอดภัยพอสำหรับระบบภายในโรงเรียน แต่**ต้องบังคับรหัสผ่านที่ไม่ซ้ำกับบัญชีอื่น** |
| เซสชัน | หมดอายุอัตโนมัติใน 8 ชั่วโมง | ครูต้องเข้าสู่ระบบใหม่ทุกวัน |

**เมื่อใดควรย้ายไปฐานข้อมูลจริง** — ถ้านักเรียนเกิน 3,000 คน หรือต้องเชื่อมกับระบบอื่นของโรงเรียน
โครงสร้าง PostgreSQL ที่ออกแบบไว้ครบแล้วอยู่ที่ `db/schema.sql` ย้ายข้อมูลจาก Sheets ได้ตรง ๆ

## การสำรองข้อมูล (สำคัญมาก)

Google Drive มีประวัติเวอร์ชันให้อยู่แล้ว แต่ยังไม่พอ ควรทำเพิ่ม

1. **ทุกสิ้นเดือน** — ไฟล์ → ดาวน์โหลด → Microsoft Excel เก็บไว้นอก Google Drive
2. **ทุกสิ้นภาคเรียน** — ไฟล์ → ทำสำเนา ตั้งชื่อ `สำรอง 2569 ภาค 1`
3. **ทดสอบกู้คืนอย่างน้อยปีละครั้ง** — เปิดไฟล์สำรองแล้วตรวจว่าข้อมูลครบจริง
   การสำรองข้อมูลที่ไม่เคยทดสอบกู้คืน เท่ากับไม่มีการสำรองข้อมูล

## แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุและวิธีแก้ |
|-------|-----------------|
| ไม่มีเมนู ⚙️ ในไฟล์ Sheets | ยังไม่ได้บันทึกไฟล์ใน Apps Script หรือยังไม่ได้โหลดหน้า Sheets ใหม่ |
| `ไม่พบชีต "..."` | ยังไม่ได้รันเมนู **ติดตั้งระบบ** |
| เข้าเว็บแอปแล้วขึ้นหน้าขาว | ตรวจว่าสร้างไฟล์ HTML ครบทั้ง 5 ไฟล์และชื่อตรงตามตาราง |
| ล็อกอินแล้วเด้งออกบ่อย | เซสชันหมดอายุ 8 ชั่วโมง ปรับได้ที่ `APP.SESSION_HOURS` ใน `00_Config.gs` |
| ดาวน์โหลดรายงานไม่ได้ | เบราว์เซอร์บล็อกการดาวน์โหลดในเฟรม ลองเปิดเว็บแอปในแท็บใหม่ หรือใช้ Chrome |
| คะแนนไม่ตรงกับประวัติ | **ตั้งค่าระบบ → เครื่องมือ → คำนวณคะแนนคงเหลือใหม่** |
| แก้โค้ดแล้วเว็บแอปไม่เปลี่ยน | ต้อง **Deploy → จัดการการทำให้ใช้งานได้ → ✏️ แก้ไข → เวอร์ชัน: ใหม่** ทุกครั้ง |
| ครูลืมรหัสผ่าน | ผู้ดูแลระบบเข้า **ตั้งค่าระบบ → ผู้ใช้งาน → แก้ไข** แล้วตั้งรหัสผ่านใหม่ให้ |

## โครงสร้างโค้ด

```
apps-script/
├── appsscript.json     ตั้งค่าโครงการและสิทธิ์ที่ระบบขอ
├── 00_Config.gs        ค่าคงที่ โครงสร้างชีต บทบาทและตารางสิทธิ์
├── 01_Db.gs            ชั้นเข้าถึงข้อมูล อ้างอิงคอลัมน์ด้วยชื่อหัวตาราง มีแคชและล็อก
├── 02_Auth.gs          เข้ารหัสรหัสผ่าน เซสชัน ตรวจสอบสิทธิ์ จัดการผู้ใช้
├── 03_Scoring.gs       กลไกคะแนน 2 บัญชี บัญชีเดินคะแนน และกระดานเกียรติยศ
├── 04_Api.gs           ฟังก์ชันที่หน้าเว็บเรียก (28 ตัว) ทุกตัวตรวจสิทธิ์ก่อนเสมอ
├── 05_Reports.gs       สร้างรายงาน 9 ประเภท และแปลงเป็น Excel/PDF
├── 06_Setup.gs         เมนูติดตั้ง ข้อมูลตั้งต้น หลักเกณฑ์ 45 ข้อ ข้อมูลตัวอย่าง
├── 07_WebApp.gs        doGet และ API สาธารณะของกระดานเกียรติยศ
├── Index.html          โครงหน้าเว็บ
├── Style.html          ระบบดีไซน์ทั้งหมด (รองรับโหมดมืดและจอมือถือ)
├── Script.html         แกนหลัก: เรียก API เราเตอร์ เข้าสู่ระบบ ส่วนประกอบร่วม
├── ScriptCharts.html   กราฟ SVG ที่เขียนเอง ไม่ต้องโหลดไลบรารีภายนอก
└── ScriptViews.html    หน้าจอทั้ง 8 หน้า
```

**หลักที่ยึดในการเขียน**

- ตรวจสอบสิทธิ์ที่**ฝั่งเซิร์ฟเวอร์เสมอ** การซ่อนปุ่มบนหน้าจอเป็นเพียงความสะดวก ไม่ใช่ความปลอดภัย
- ทุกการเปลี่ยนคะแนนต้องมีรายการในชีต `บัญชีคะแนน` ตรวจสอบย้อนหลังได้ว่าใครให้ เมื่อไร ด้วยเหตุใด
- อ้างอิงคอลัมน์ด้วย**ชื่อหัวตาราง** ครูจึงสลับหรือแทรกคอลัมน์ในชีตได้โดยระบบไม่พัง
- ไม่โหลดไลบรารีจากภายนอกเลย (ยกเว้นฟอนต์) โรงเรียนที่เน็ตช้าจึงใช้งานได้
