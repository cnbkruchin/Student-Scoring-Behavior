## 6.2 รายงานที่ควรให้ความสำคัญเป็นพิเศษ

### R01 ระเบียนความประพฤติรายบุคคล
เอกสารที่ผู้ปกครองจะเห็นบ่อยที่สุด ควรประกอบด้วย
- หัวกระดาษราชการ ตราโรงเรียน ชื่อ-สกุล รหัส ห้อง ครูที่ปรึกษา
- กราฟเส้นแสดงคะแนนความประพฤติตลอดปี (เห็นแนวโน้มดีขึ้น/แย่ลงได้ทันที)
- ตารางเหตุการณ์เรียงตามเวลา แยกสีความดี (เขียว) / ความผิด (ส้ม)
- **ให้ส่วนความดีอยู่ก่อนส่วนความผิดเสมอ** ผู้ปกครองจะรับฟังได้ดีขึ้นมาก
- ช่องลงนามครูที่ปรึกษาและผู้ปกครอง

### R03 นักเรียนกลุ่มเสี่ยง
รายงานที่สร้างผลลัพธ์จริงมากที่สุด เพราะเปลี่ยนระบบจาก "บันทึกไว้เฉย ๆ" เป็น "ลงมือช่วย"
ต้องแสดงคู่กันเสมอว่า **ตอนนี้ใครกำลังช่วยนักเรียนคนนี้อยู่ และดำเนินการถึงไหนแล้ว**
ไม่ใช่แค่รายชื่อคนคะแนนต่ำ

### R04 พฤติกรรมที่พบบ่อย
มีค่าเชิงบริหารสูง เพราะบอกได้ว่าควรแก้ที่ระบบ ไม่ใช่ที่ตัวเด็ก
ตัวอย่างจริงที่มักพบ: "มาสาย" กระจุกวันจันทร์ช่วง 07:50–08:10 ที่ประตูหลัง
→ แก้ด้วยการจัดครูเวรและปรับเวลารถรับส่ง ได้ผลกว่าการหักคะแนนเด็กทีละคน

### R07 สถิติการบันทึกรายครู
ตรวจสอบความเป็นธรรมของระบบ สัญญาณอันตรายที่ควรเฝ้าดู
- ครูที่บันทึกเฉพาะความผิด ไม่เคยให้คะแนนความดีเลย
- ครูที่บันทึกมากผิดปกติเทียบกับค่าเฉลี่ย (อาจใช้ระบบเป็นเครื่องมือกดดันนักเรียน)
- ครูที่ไม่เคยบันทึกเลยทั้งภาคเรียน (ระบบยังเข้าไม่ถึงคนกลุ่มนี้)
- อัตราการถูกปฏิเสธสูง (เข้าใจเกณฑ์คลาดเคลื่อน ต้องอบรมเพิ่ม)

> รายงานนี้ควรใช้เพื่อ **พัฒนาระบบและอบรมครู** ไม่ใช่ประเมินความดีความชอบของครู
> มิฉะนั้นจะเกิดการบันทึกเพื่อทำยอด ซึ่งทำลายคุณภาพข้อมูลทั้งหมด

### R10 + R14 คุณลักษณะอันพึงประสงค์ 8 ประการ
จุดเชื่อมที่ทำให้ระบบ "คุ้มค่ากับงานที่ครูลงแรง" มากที่สุด
ทุกเกณฑ์คะแนนความดีถูกจับคู่กับคุณลักษณะอันพึงประสงค์ไว้แล้วในคอลัมน์ `behavior_rules.desired_trait`
เมื่อถึงปลายภาค ครูที่ปรึกษาไม่ต้องนั่งนึกย้อนว่าเด็กคนนี้ควรได้ระดับใด
ระบบแสดงหลักฐานเชิงประจักษ์ให้เลย และงานประกันคุณภาพนำไปใส่ SAR มาตรฐานที่ 1 ได้ทันที
